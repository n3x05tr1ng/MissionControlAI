# 02 — Data Contracts (single source of truth)

Every phase references this file. Define all of this in
`src/lib/contracts.ts` as TypeScript types and document it in the README.
If any phase file disagrees with this one, **this file wins**.

---

## 1. Project registry

App-level file at the repo root.

- `projects.config.json` — real config, **gitignored**.
- `projects.config.example.json` — committed template.

```json
{
  "projects": [
    {
      "id": "proyeccion",
      "name": "Proyeccion",
      "path": "/absolute/path/to/repo",
      "description": "Short one-line description"
    }
  ]
}
```

`id` is a stable slug used in URLs and as a DB key. `path` is an absolute path
to a local git repo.

---

## 2. Per-project state — `.claude/state.json`

Lives **inside each target repo** at `.claude/state.json`. Machine-readable.
Written by the Orchestrator after a run (Phase 2).

```json
{
  "projectId": "string",
  "status": "idle | running | needs-input | blocked | done",
  "nextStep": "string — one line, the single most important next action",
  "blockers": ["string"],
  "openQuestions": ["string"],
  "lastSession": {
    "id": "string",
    "endedAt": "ISO string",
    "model": "string",
    "result": "success | error",
    "costUsd": 0,
    "tokens": { "input": 0, "output": 0 },
    "filesTouched": ["string"]
  },
  "updatedAt": "ISO string"
}
```

`lastSession` is `null` when the project has never been run. Code must render
gracefully when `.claude/state.json` is missing entirely.

---

## 3. Per-project handoff — `.claude/handoff.md`

Lives inside each target repo at `.claude/handoff.md`. Human-readable, narrative.
**Written by the agent itself** as the final step of a run (Phase 2 sends an
instruction telling it to). Parsed by the dashboard by heading.

Fixed sections — exact headings, exact order:

```markdown
# Handoff — <project name> — <ISO date>

## Done this session

## Next step

## Blockers

## Open questions

## Files touched

## Context for next run
```

The parser keys on the `##` headings. Unknown sections are ignored. Missing
file → show "No handoff yet".

## 5. Project index (SQLite — `project_index` table)

A denormalized snapshot upserted whenever the app reads a project, so the

| Column | Type |

| `next_step` | TEXT |
| `last_session_at` | TEXT |

## 6. Reminder (SQLite — `reminders` table)

```json
{
  "id": "string",
  "projectId": "string | null",
  "message": "string",
  "dueAt": "ISO string",
  "kind": "manual | auto-nudge",
  "status": "pending | fired | dismissed",
  "createdAt": "ISO string"
}
```

`projectId` null = a general reminder not tied to a project.
`auto-nudge` = generated by the scheduler for stale projects (Phase 5).

Table columns: `id` PK, `project_id`, `message`, `due_at`, `kind`, `status`,
`created_at`.

---

## 7. Notification (SQLite — `notifications` table)

History log of everything the app surfaced to the user.

```json
{
  "id": "string",
  "projectId": "string | null",
  "type": "run-complete | reminder | nudge",
  "title": "string",
  "body": "string",
  "createdAt": "ISO string"
}
```

Table columns: `id` PK, `project_id`, `type`, `title`, `body`, `created_at`.

## 8. Launch flags (Prompt Composer — Phase 3)

The shape passed from the Prompt Composer to the Engine launch endpoint.

```json
{
  "rawPrompt": "string — what the user typed",
  "finalPrompt": "string — after optional improvement",
  "planMode": false,
  "useSubagents": false,
  "model": "string — a model id from app.config.json",
  "allowedTools": ["string"]
}
```

Mapping to Agent SDK options:
- `planMode` → `permissionMode: 'plan'`
- `useSubagents` → populate the SDK `agents` option
- `model` → SDK `model` option
- `allowedTools` → SDK `allowedTools` option

---

## 9. App config — `app.config.json` (committed)

Holds values that change over time so they are not buried in code. Notably the
list of selectable model ids. **Do not hardcode model strings in components.**
Verify current model ids from official docs when populating this file.

```json
{
  "models": [
    { "id": "<verify-current-id>", "label": "Opus" },
    { "id": "<verify-current-id>", "label": "Sonnet" }
  ],
  "assistantModel": "<verify-current-id>",
  "autoNudgeAfterDays": 3
}
```
